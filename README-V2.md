# Kouame-Auto V2 — Phase 1 : page d’accueil

## Démarrage
Ouvrez `index.html` dans votre navigateur ou lancez un serveur local depuis ce dossier :

```sh
python -m http.server 8000
```

Puis ouvrez http://localhost:8000.

## Modifications
- Nouvelle page d'accueil moderne et responsive (`index.html` + `accueil-v2.css`).
- Bootstrap 5.0.2 chargé **localement avec chemins relatifs** sur les pages HTML à la racine.
- Les anciens liens `page acceuil.html` pointent vers `index.html`.
- Les autres pages conservent leur conception et seront modernisées ultérieurement.

## À noter
Les liens et formulaires hérités des anciennes pages peuvent encore être incomplets. Aucun backend ni paiement réel n'est implémenté. La police Google Fonts est facultative et dispose de polices de repli hors ligne.
